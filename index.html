Metodología de Extracción y Estimación

Este observatorio monitorea continuamente las variaciones de la divisa estadounidense (USD) en Bolivia en sus distintas vertientes: el tipo de cambio oficial, las mesas de dinero bancarias y el mercado P2P (USDT).

1. Fuentes de Datos

  • Banco Central de Bolivia (BCB): Se extrae el tipo de cambio regulado oficial (6.86 compra / 6.96 venta).
  • Banca Múltiple: Cotizaciones publicadas en los portales web y tableros oficiales de las entidades supervisadas por ASFI.
  • Binance P2P (Dólar Digital / USDT): Datos extraídos del libro de órdenes entre pares en Bolivia.

2. Frecuencia y Automatización

Los datos se actualizan de forma programada mediante GitHub Actions cada cierto intervalo de tiempo. Los resultados se serializan en archivos planos .csv dentro del repositorio para garantizar disponibilidad pública y sin intermediarios.

3. Dólar Paralelo y P2P

A diferencia del sistema bancario tradicional que maneja un precio estático de referencia, Binance P2P cuenta con un libro de órdenes abierto. Para representar la cotización se toma en cuenta el precio de las órdenes activas de mayor liquidez y disponibilidad inmediata en el mercado boliviano.

Datos recopilados automáticamente vía GitHub Actions.
